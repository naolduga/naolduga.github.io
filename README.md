##### <a href="https://man.openbsd.org/whoami.1">whoami</a>?


Since graduating in 2007 with a degree in engineering, I've done diverse <a href="https://linkedin.com/in/naolduga">work</a> both in academia and industry. In 2017, I founded <a href="http://synestate.com">Synestate</a> to pursue business and independent studies. I'm based in Brooklyn, New York.

In 2013/4 I created <a href="http://bitgadaa.org">BitGadaa</a> based on the <a href="https://naolduga.com/TelosVM">TelosVM</a> concept from my PhD years (at the University of Amsterdam; I've since dropped out). I've been studying <a href="https://github.com/naolduga/bitcoin">bitcoin</a> for 7+ years. Lately I work on global banking, markets & merchant processing technology.

I'm fascinated by <a href="https://naolduga.keybase.pub/old_docs/TheVirtualizationLandscape.pdf">virtual</a> <a href="http://ceur-ws.org/Vol-965/paper02-essos2013.pdf">machine</a>ry and computational <a href="https://plato.stanford.edu/entries/agency/">agency</a>, esp. when the <a href="https://github.com/naolduga/awesome-blockchain">blockchain</a> paradigm meets <a href="https://en.wikipedia.org/wiki/Software_agent">software agents</a>.
