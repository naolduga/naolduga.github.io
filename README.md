##### <a href="https://man.openbsd.org/whoami.1">whoami</a>?

<p>

I'm a programmer who's been navigating the <a href="https://github.com/naolduga/bitcoin">bitcoin</a> space for 6+ years.

In 2013/4 I created <a href="http://bitgadaa.org">BitGadaa</a> based on the <a href="https://naolduga.keybase.pub/old_docs/ASCI_A9_N.D.Jebessa_P2P_Web_of_Trust_Calculi_and_Promise_Games.pdf">TelosVM</a> concept from my PhD years (at the University of Amsterdam; I've since dropped out).

I'm fascinated by <a href="https://naolduga.keybase.pub/old_docs/TheVirtualizationLandscape.pdf">virtual machine</a>ry and computational <a href="https://plato.stanford.edu/entries/agency/">agency</a>, esp. when the <a href="https://github.com/naolduga/awesome-blockchain">blockchain</a> paradigm meets <a href="https://en.wikipedia.org/wiki/Software_agent">software agents</a>.

Since graduating in 2007 with a degree in engineering, I've done diverse <a href="https://linkedin.com/in/naolduga">work</a> both in academia and industry.

At present I do business and independent R&D at <a href="http://synestate.com">Synestate</a> (based in Brooklyn, New York).
