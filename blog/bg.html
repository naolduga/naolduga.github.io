BG + Raft

Here I use the Raft consensus protocol to mimic Gadaa. Built on a Rust and WebAssembly port of RaftScope.

This is roughly based on my BG work from 2014 (I was a distributed systems nerd then). Read the Raft-inspired paper here. Feedback is welcome.

Raft is used in etcd which is used in Kubernetes. The name Kubernetes comes from the Greek kubernētēs, helmsman, the same root as governor and cybernetics. Production infrastructure is, quite literally, governed by a consensus protocol. My original BG work was a new media art-themed work on governance so it all checks out, I guess.
